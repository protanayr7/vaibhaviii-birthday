# Birthday site

Static site. Files: `index.html`, `song.mp3`, `photo1.jpg` to `photo6.jpg`. Keep them all in the same folder.

## Put it online with GitHub Pages
1. Create a GitHub account and a **public** repository (for example `vaibhaviii-birthday`).
2. Click **Add file → Upload files**, drag in every file from this folder (not the folder itself), then **Commit changes**.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
4. Wait 1 to 2 minutes. Your link will be `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Editing
All text lives in the `CONFIG` section inside `index.html`. To change a photo, replace the matching `photoN.jpg` with the same file name.
